# RPI Crafts Club Link Page

Open `index.html` in a browser to view the page.

## Quick edits

- Links and button text: edit `index.html` inside the `link-list` section.
- Club title and subtitle: edit the `club-header` section in `index.html`.
- Colors: edit the variables at the very top of `style.css`.
- Images: replace files in the `assets` folder, or change their paths in `index.html`.

The page is plain HTML and CSS, so it can be hosted on GitHub Pages or any static site host.
